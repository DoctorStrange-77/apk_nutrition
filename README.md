# APK Nutrition

Applicazione Android locale per generazione automatica di menu nutrizionali.

## Obiettivi
- nessun login o autenticazione
- nessuna dipendenza da Supabase per il funzionamento ordinario
- macro impostati direttamente dall'utilizzatore
- timing creati e gestiti nell'app
- motore nutrizionale V2 derivato dal progetto Builder
- alimenti, timing, target e menu salvati sul dispositivo
- packaging Android tramite Capacitor

> `DoctorStrange-77/Builder` è usato esclusivamente come sorgente di riferimento per il motore e non viene modificato da questo progetto.
